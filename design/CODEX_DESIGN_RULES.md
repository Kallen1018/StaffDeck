# MindStaff Codex 设计规则

本文件用于约束 Codex 在 `MindStaff_Front` 项目中的默认 UI 实现方式。除非用户明确要求偏离，否则所有前端页面、组件、交互和视觉样式都应默认遵循本规则。

## 规范来源

- 视觉展示稿：`design/design-system.html`
- Token 单一数据源：`design/css/tokens.css`
- 应用外壳与交互基线：`design/css/app.css`
- 页面与组件还原样式：`design/css/pages.css`

Codex 在执行任何 UI 任务前，应先阅读以上文件，再决定具体实现。

## 总体实现原则

- 保持企业级知识管理产品的视觉气质：克制、清晰、轻量、稳定。
- 优先使用 `tailwindcss` + `naiveUI` 实现，不要引入与现有设计语言冲突的新框架风格。
- 优先复用设计 Token、已有状态色和页面骨架，不要随意新增十六进制颜色、字号、间距、圆角或阴影值。
- 如需新增样式，先从现有 Token 中组合；只有现有 Token 无法表达时，才新增，并应保持同一设计语言。
- 如果用户没有明确要求，不要生成偏炫技风格，例如强玻璃拟态、霓虹、过重渐变、夸张阴影、紫色主视觉或与业务无关的装饰。

## 色彩规则

优先使用 `design/css/tokens.css` 中的变量，不要硬编码颜色。

核心颜色如下：

- 主色：`--color-primary: #2563EB`
- 主色文字：`--color-primary-text: #1F5FEF`
- 主色浅底：`--color-primary-50: #EFF4FF`
- 页面底色：`--color-page: #F7F8FA`
- 卡片底色：`--color-surface: #FFFFFF`
- 次级底色：`--color-surface-2: #F2F5FA`
- 常规边框：`--color-border: #E5E6EB`
- 强边框：`--color-border-strong: #D0D3D9`
- 主文本：`--color-text: #1F2329`
- 深标题：`--color-text-strong: #10182B`
- 次文本：`--color-text-secondary: #646A73`
- 说明文本：`--color-text-caption: #8F959E`

语义色保持 Naive UI 调性：

- 成功：`--color-success: #18A058`
- 警告：`--color-warning: #F0A020`
- 错误：`--color-error: #D03050`
- 信息：`--color-info: #2080F0`

## 字体规则

- 默认字体栈使用 `--font-sans`。
- 字号层级优先使用以下 Token：
- `--fs-display: 36px`
- `--fs-h1: 28px`
- `--fs-h2: 22px`
- `--fs-h3: 18px`
- `--fs-body-lg: 16px`
- `--fs-body: 14px`
- `--fs-caption: 12px`
- 字重优先使用 `400 / 500 / 600 / 700`，避免出现无意义的零散字重。

## 间距与圆角规则

- 采用 4px 基准间距体系。
- 优先使用：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 48 / 64`。
- 圆角优先使用：`4 / 6 / 8 / 12 / 16 / full`。
- 不要频繁引入 10、14、18、22 这类游离值，除非已有上下文明确存在。

## 页面骨架规则

- 整体页面通常采用浅灰页面背景 + 白色内容容器的组合。
- 卡片、表单、列表、面板应使用白底、浅边框、中小圆角，保持信息密度和可读性。
- 常规卡片风格应接近：
- 白色背景
- 1px 浅边框
- `12px` 左右圆角
- 轻阴影或无阴影
- 页面顶部、侧栏、主内容区之间的分层要依靠留白、边框和浅底色，而不是重视觉特效。

## 导航规则

侧栏导航与顶部标签必须使用同一套状态表达，不允许风格割裂。

默认规则：

- 未选中：主文本色 `#1F2329`，字重 `500`
- 选中态：主色文字 `#1F5FEF`，字重 `600`，浅底 `#EFF4FF`
- 悬停态：优先使用浅底和主色文字，不要使用高饱和整块填充
- 功能模块导航与辅助筛选标签要区分层级，辅助标签可使用 `--color-text-slate-3`

## 基础组件规则

### Button

- 主按钮使用主色实底、白字、中等字重。
- 次按钮使用白底 + 边框 + 次文本色。
- 常用高度以 `40px` 或 `44px` 为主。

### Input / Select

- 输入框默认白底、浅边框、中小圆角。
- 聚焦态使用主色边框和浅色 focus ring。
- 占位符使用说明文本或 placeholder token，不要过深。

### Tag / Chip

- Tag 使用语义色体系，表达状态。
- Chip 使用中性浅底，激活态可切换为主色实底。

### Avatar

- 默认采用纯色圆形底，优先主色或主色浅底方案。

### Pagination

- 当前页优先主色实底。
- 非当前页使用浅底或白底，保持清爽和可点击感。

## 响应式规则

- 页面在桌面端优先保持中高信息密度。
- 在平板和移动端优先保证结构不破坏，允许纵向堆叠，但不要丢失层级关系。
- 响应式调整优先收缩留白和改为换行，不要先破坏组件状态样式。

## 技术实现建议

- 在 Vue 组件中优先使用 Tailwind 工具类结合 CSS 变量。
- 需要复用时，优先提炼为共享组件或局部样式，而不是在页面里重复硬编码。
- 使用 Naive UI 时，应尽量通过 `themeOverrides` 或包裹层样式贴近本设计系统。
- 若设计 Token 已存在，应引用变量，而不是复制数值。

## 决策优先级

当多个信息源冲突时，按以下优先级处理：

1. 用户当前明确要求
2. 本文件 `design/CODEX_DESIGN_RULES.md`
3. `design/css/tokens.css`
4. `design/design-system.html`
5. `design/css/app.css` 与 `design/css/pages.css`

如需偏离本规范，除非用户已明确要求，否则应先说明偏离点再执行。
